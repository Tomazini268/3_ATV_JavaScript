Terceira Atividade em JavaScript – Somatória de Números

Descrição

Projeto básico em JavaScript que realiza a leitura de dois números inteiros, efetua a soma entre eles e exibe o resultado na página HTML.

 Objetivo

Capturar dados numéricos com window.prompt()

Converter valores de texto para inteiro usando parseInt()

Realizar operações matemáticas em JavaScript

Exibir o resultado com document.write()

Tecnologias

HTML

JavaScript

Funcionamento

O sistema solicita dois números inteiros ao usuário

Os valores são convertidos para inteiro

A soma é calculada

O resultado é exibido na tela no formato: “O resultado da soma = X”
